CVS STUDY HUB – SECTION A2 (Android)

WHAT'S INCLUDED
- index.html: a standalone version that can be opened directly in a browser.
- manifest.webmanifest + sw.js + icons/: PWA install/offline support when hosted on HTTPS.
- app.js + data.js + styles.css: application files.

QUICK USE ON ANDROID
1) Copy CVS_Study_Hub_A2.html to your Android phone.
2) Open it with Chrome (or another modern browser). If it opens in a file viewer, use Share/Open with > Chrome.
3) The standalone file is useful for direct opening; browser storage policies for file URLs can vary. Check the top status indicator says محفوظ after opening.
4) For dependable persistent storage and home-screen installation, publish the PWA folder over HTTPS and use that address. Export a JSON backup periodically.

INSTALL AS A HOME-SCREEN APP (PWA)
1) Extract this ZIP.
2) Upload the CONTENTS of the cvs_android_app folder to any static HTTPS hosting service (the folder must serve index.html at its root).
3) Open the HTTPS address in Chrome on Android.
4) Choose Install app / Add to Home screen from Chrome's menu, or use the Install app prompt if shown.
5) After first successful load, the app shell is cached and is available offline. Progress remains stored on the device/browser profile.

DATA & PRIVACY
- No account and no app backend are used. The tracker data stays in local browser storage on the device.
- The PWA requires HTTPS (or localhost for testing) for installability and service-worker offline caching.
- Clearing browser/site data can erase progress. Export a JSON backup first.
- To move to another phone/browser, export the JSON backup on the old device and import it on the new one.
